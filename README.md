### Godot Island Generator

*Procedural generation · Godot · GDScript · Custom shaders*

A procedural island generator for **Godot**:

- Procedural island terrain with automatic biome mapping (sand, grass, rock, snow)
- Dynamic water with animated waves, Fresnel reflections and depth-based color blending
- Custom terrain and water shaders
- Stylized toon shading with outline effect
